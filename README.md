Welcome to Olympus.

This project is built from actual development, testing, and continuous improvement — not from blindly copying someone else's work.

For Skidders

If your development process is:

1. Find a script.
2. Copy it.
3. Rename it.
4. Claim it as yours.
5. Repeat.

Congratulations. You have successfully contributed nothing.

Credits are free. Give them.

Reminder

- Don't claim other people's work as your own.
- Don't remove credits.
- Don't leak private or unreleased code.
- Learn how the code works instead of just copying it.
- If you use someone else's work, respect the original creator.

«Copying code can make your project run.
It doesn't make you a developer.»

— Olympus
